02 / COMPATIBILITY

Current support and limitations

  • The public version is the 0.1.8 BRP core, targeting Unity 2021.3 / 2022.3. URP is a separate add-on and is not included in the BRP core.
  • VRChat PC requires manual validation and has not completed release certification. VRChat Quest is not a direct runtime target. Warudo testing on the target runtime is pending.
  • 2D rim light, 2D shadows, and inner 2D edges depend on camera depth supplied by the host. Avatars cannot force depth availability in the normal VRChat player view.
  • The lilToon converter is an interoperability tool, not a mathematical reproduction. No verified GPU ms or SetPass improvement figures are provided; performance and successful uploads are not guaranteed.
  • Validate shader compilation, tests, full-body and face appearance, builds, and runtime behavior in your target environment.

Old Assets installations: back up the project and exit Play mode, then delete Assets/StudioRaming/MingToon before installing the new package. Move personal materials, presets and textures out first. Do not delete the entire Assets/StudioRaming folder or MLC. Existing package installations should update through their current installation method.

VCC did not open?

In VCC, open Settings → Packages → Add Repository, paste the URL below and select Add. Check MingToon Core and the MingToon package, confirm I Understand, Add Repository, then add MingToon in Manage Project for your target project.
