오픈 베타 참여 안내

다운로드 전에 현재 베타의 이용 조건과 지원 범위를 확인해 주세요.

01 / TERMS

이용 조건

  1. 오픈 베타는 무료 평가용 개발 빌드입니다. 아직 완성되지 않았으며 기능과 구성은 변경될 수 있습니다. 비상업적 이용자에겐 무상 제공됩니다.
  2. 현재 모든 상업적 이용은 금지됩니다. 수익화 방송·영상, 에셋·프리셋 판매, 유료 아바타 커미션에 사용할 수 없습니다. 상업 라이선스 판매는 Early Access부터 시작합니다.
  3. 개인 아바타 제작, 비수익 콘텐츠, 학습·실험 등 모든 비상업 활동에 사용할 수 있습니다.
  4. MingToon 본체와 Ming Light Controller의 파일 공유·재배포·판매는 금지됩니다. 원본, 복사본, 수정본, 추출한 코드·셰이더 및 이를 포함한 프로젝트도 해당합니다.
  5. 모든 라이선스에서 소스 코드 자체의 판매는 금지됩니다. 향후 상업 라이선스의 권한은 현재 베타에 적용되지 않습니다.

02 / COMPATIBILITY

현재 지원 범위와 제한

  • 공개 버전은 0.1.8 BRP 코어이며 Unity 2021.3 / 2022.3을 대상으로 합니다. URP는 BRP 본체에 포함되지 않는 별도 애드온입니다.
  • VRChat PC는 수동 검증 대상이며 출시 인증이 완료되지 않았습니다. VRChat Quest는 직접 실행 대상이 아니며, Warudo 실기 검증은 대기 중입니다.
  • 2D 림라이트·2D 그림자·내부 2D 경계는 호스트의 카메라 깊이 제공에 의존합니다. VRChat 일반 플레이어 화면에서는 아바타가 깊이를 강제할 수 없습니다.
  • lilToon 변환은 상호 운용 도구이며 결과를 수학적으로 복제하지 않습니다. 검증된 GPU ms·SetPass 개선 수치는 제공하지 않으며 성능과 업로드 성공을 보장하지 않습니다.
  • 사용할 대상 환경에서 셰이더 컴파일, 테스트, 전신·얼굴 확인, 빌드 및 실기 동작을 직접 검증해 주세요.

03 / DOWNLOAD

배포 안내

원하는 방법으로 MingToon을 설치하세요.

VCC

저장소를 추가한 뒤 Manage Project에서 MingToon을 설치하세요.

VCC에 추가↗

BOOTH

BOOTH에서 설치기를 받은 뒤 Unity에 가져오세요. 인터넷에 연결하면 MingToon이 자동으로 설치됩니다.

BOOTH에서 다운로드↗

기존 Assets 버전 사용자: 프로젝트를 백업하고 Play 모드를 종료한 뒤, 새 패키지를 설치하기 전에 Assets/StudioRaming/MingToon 폴더를 삭제하세요. 그 안에 직접 저장한 머티리얼·프리셋·텍스처는 먼저 폴더 밖으로 옮겨 보관하세요. Assets/StudioRaming 전체나 MLC 폴더는 삭제하지 마세요. 이미 패키지로 설치했다면 기존 설치 방법으로 업데이트하세요.

VCC가 열리지 않나요?

VCC의 Settings → Packages → Add Repository에서 아래 주소를 붙여넣고 Add를 누르세요. MingToon Core 저장소와 MingToon 패키지를 확인하고 I Understand, Add Repository를 선택한 뒤, 대상 프로젝트의 Manage Project에서 MingToon을 추가하세요.

유료 라이선스 관리를 위한 별도 플랫폼이 향후 추가될 수 있습니다.

버그는 공식 Discord 서버의 버그 제보 채널로 알려 주세요. ↗
